I work on **Developer Relations at [Baseten](https://www.baseten.co)** and on **Agent Experience and Developer Experience at [Blaxel](https://blaxel.ai)**, now part of Baseten.

Baseten runs inference for production AI. Blaxel gives agents fast, isolated sandboxes to work in. My job is to make that whole surface feel obvious: SDKs, CLIs, docs, cookbooks, integrations and workflows that developers can ship with on day one and that coding agents can operate directly, without a human translating in between.

## What I do

- **Agent experience.** Design the CLI, SDK, skill and MCP surfaces so agents like Claude Code, Codex and Cursor can drive Blaxel end to end.
- **Developer experience.** Own the path from first `bl` command to production: onboarding, docs, examples, error messages, integrations with the frameworks people already use.
- **Developer relations.** Tutorials, cookbooks, launches, talks and the feedback loop back into the product, across Baseten and Blaxel.

## Things I have built

**[SystemSculpt AI](https://github.com/SystemSculpt/obsidian-systemsculpt-ai)**, an agent workspace for Obsidian, with 37k+ downloads and 190+ GitHub stars.

I am most useful when the problem is ambiguous, the surface area is large, and someone needs to own the whole path from product shape to implementation to adoption.
